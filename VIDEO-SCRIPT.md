## PRODUCTION NOTES

### Screen Recordings Needed
Record these in SupaDev (the actual VaultBot Mac app):

1. **Pipeline run** — Start a new pipeline task, show all 6 stages progressing, show the review screen with diffs, click approve
2. **Ghost completions** — Open a Swift file, start typing, show ghost text, Tab to accept
3. **⌘K command bar** — Select code, press ⌘K, type instruction, show diff
4. **Error fix** — Introduce a typo, build, show sparkle icon, click fix
5. **Option+Click docs** — Option+Click on a symbol, show the floating panel
6. **Git blame** — Click blame in status bar, show Gravatar popup
7. **Source control** — Show the source control panel, stage files, generate AI commit message
8. **Theme switching** — Quick flashes through 4-5 different themes
9. **Build & Run** — Click ▶, show build output, app running
10. **Debugging** — Set breakpoint, run, hit breakpoint, inspect variables

### Tips for Screen Recording
- Use **macOS screen recording** (⌘⇧5) or OBS
- Resolution: **1920x1080** minimum, 4K preferred
- **Hide the dock** (⌘⌥D) for cleaner look
- Use a **clean project** with simple code for demos
- **Zoom in** on relevant parts (editor area, pipeline sidebar)
- Record **without audio** — add voiceover in post

### Music
- Lo-fi beats or tech/startup background music
- Keep it subtle, don't overpower the voiceover
- Free options: YouTube Audio Library, Artlist (if you have subscription)

### Editing Tools
- **Final Cut Pro** or **DaVinci Resolve** (free) for editing
- **Canva** for animated text overlays
- **After Effects** or **Motion** for logo animation

### Color Grading
- Match SupaDev's dark theme: dark backgrounds, purple/cyan accents
- Keep text overlays in the same color scheme (#8B5CF6 purple, #06B6D4 cyan)

### Fonts for Overlays
- **SF Pro Display** (Apple's system font) or **Inter** for clean tech look
- Bold for headings, Regular for descriptions
- White text on dark overlays with subtle transparency
